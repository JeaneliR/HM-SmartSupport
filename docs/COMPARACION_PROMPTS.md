# Evolución de los prompts

| Elemento | V1 | V2 | V3 |
|---|---:|---:|---:|
| Contexto empresarial | No | Sí | Sí |
| Rol especializado | No | Sí | Sí |
| Restricciones de seguridad | No | Básicas | Detalladas |
| Formato de respuesta | No | Breve/estructurado | Directo, pasos y cierre |
| Ejemplos | No | No | Three-shot |
| Información desconocida | No | No inventar | Pide datos y declara límites |
| Fuera de dominio | No | Implícito | Regla y ejemplo explícitos |
| Uso del historial | No | Implícito | Explícito |

Para el informe, ejecuta las mismas tres consultas con V1, V2 y V3 desde el
selector lateral y pega resultados reales. Consultas sugeridas:

1. “Mi remalladora bota humo y huele a quemado.”
2. “¿Tienen la cuchilla XZ-999 y cuánto cuesta?”
3. “¿Quién ganará el partido de mañana?”

La conclusión debe basarse en las respuestas observadas, no solo en la teoría.
